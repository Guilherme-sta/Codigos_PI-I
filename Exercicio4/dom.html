Diferença entre as propriedades textContent, innerText e innerHTML

Essas três propriedades servem para ler ou alterar conteúdo de elementos HTML, mas cada uma se comporta de forma diferente:

Exemplo para comparação: <div id="exemplo">Olá <b>mundo</b></div>

Olá mundo(texto oculto)
TextContent

Diferenças:

  • Retorna todo o texto do elemento
  • Não interpeta tags HTML
  • Inclui textos que estão ocultos
InnerText

Diferenças:

  • Retorna apenas o texto visível na tela
  • Considera quebras de linha e layout
  • Não inclui textos que estão ocultos
InnerHTML

Diferenças:

  • Retorna o conteúdo HTML completo
  • Interpeta tags
